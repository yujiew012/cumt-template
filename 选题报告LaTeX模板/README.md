# 中国矿业大学研究生选题报告 LaTeX 模板

基于 [OpenCUMT/thesis-latex](https://github.com/OpenCUMT/thesis-latex)，上游提交 `723f159227a7567ad638dbf69f043b1783b72170`。
`cumtthesis.cls`、`Assets/` 和 `LICENSE` 保留上游内容；报告适配集中在 `report-format.sty`、`cover.tex` 和主文件中。

## 使用

1. 修改 `metadata.tex`，填写年级、学位类别、题目、学院、专业、姓名、导师和日期。
2. 在 `chapters/01-*.tex` 至 `06-*.tex` 中填写正文，将“待填写”小节名称替换为实际标题。
3. 将真实文献条目写入 `references.bib`，正文使用 `\cite{key}`；在 `main.tex` 中取消 `\ReportBibliographytrue` 的注释，启用参考文献列表。
4. 在本目录编译：

```sh
./build.sh
```

常规 TeX 环境也可使用 `latexmk -xelatex main.tex`。需要 XeLaTeX、Biber 及相应宏包，推荐完整 TeX Live/MacTeX。脚本会在 macOS Biber 通用二进制解包失败时临时提取当前架构程序，编译后删除临时程序，不修改系统安装。

Overleaf：上传本目录的 LaTeX 源文件及 `Assets/`，主文档选择 `main.tex`，编译器选择 XeLaTeX。字体沿用上游设置，包括系统的 Times New Roman、Verdana、Courier New，以及 `Assets/Fonts/` 中的中文字体。

## 文件与格式

- `main.tex`：主文档，编译输出 `main.pdf`。
- `metadata.tex`：封面可填写信息，默认留空。
- `cover.tex`：按原始 `研究生选题报告封面.doc` 的校名、年级/学位行、竖排标题、五项信息栏与落款重建；按原 DOC 的字体属性和 Word 页面坐标逐字定位，保留原横线长度、厚度和 31.2 bp 文档网格。长题目需在原填写区内排布，不自动加长横线。
- `report-format.sty`：中文章节、三级目录、无页眉文字的正文样式及参考文献页。
- `chapters/`：六章正文骨架。
- `references.bib`：空白文献库，不含示例或虚构文献。
- `研究生选题报告封面.doc`：原始封面，保持不变。

保留上游正文页边距、字体、标题字号及 GB/T 7714—2015 引文样式；去掉论文专用的双语标题、英文目录、摘要、授权声明和附录等页面。目录仅包含指定六章及其子节、参考文献，显示到 4.1.1 级。封面无页码；正文页眉文字及横线已取消，保留页脚页码；参考文献标题居中；目录使用大写罗马数字单独编号，正文从 1 开始，各章另起页，无双面打印空白页。

当前交付为可填写模板；未自动导入工作区中的研究内容或 80 篇参考文献。

## 封面精确核对（2026-10-26）

原文件的真实格式来自 Word 转存的 OOXML，而非 macOS 快速预览；快速预览会丢失中文字体和文档网格。

- 校名：华文行楷、28 磅、加粗。
- 年级/学位行：黑体、28 磅、加粗。
- 竖排“选题报告”：仿宋_GB2312、32 磅、加粗；字间基线距离 62.4 bp。
- 五项信息标签：宋体、14 磅、加粗；行间基线距离 31.2 bp。
- 制表落款：仿宋_GB2312、14 磅、加粗，原字符间距；日期为同字体 14 磅常规字重。
- 年级两条横线：57.12 / 28.56 bp 长、2.64 bp 厚；五项信息横线：164.16 bp 长、1.44 bp 厚；底部横线：439.44 bp 长、1.44 bp 厚。

字体均使用模板自带文件；`FangSong.ttf` 的字体内部名称确认为 `FangSong_GB2312`。本机 Word 初次导出曾将缺失的这个字体替代成 Arial Unicode MS，因此不能将该次导出当作仿宋字形的比对基准。LaTeX 按原文件声明的字体直接排版，不依赖该替代字形。
